Chess Analyzer's own source code is released under the MIT licence (see `LICENSE`).
The built web app bundles the components below. Because some of them are licensed under the
GNU GPL v3, **the distributed application as a whole is subject to GPL-3.0 terms**. MIT is
GPL-compatible, and the complete corresponding source is this repository (the published build also
ships source maps).

**The published app ships the licence texts.** Every build writes `THIRD-PARTY-LICENSES.md` next to
`index.html` (on the live site: https://smanahian.github.io/chess-analyzer/THIRD-PARTY-LICENSES.md).
It lists each package whose code is in the app's JavaScript or its service worker, with its version,
licence text and NOTICE file, plus this project's own licence. Vite generates the list
(`build.license` in `vite.config.ts`), and `scripts/vite-plugins.ts` adds what Vite does not see: its
own runtime helpers, the service worker's Workbox packages and the NOTICE files.
`scripts/check-dist.mjs` fails the build if a bundled package is missing from it. The engine's
licence ships as `engine/COPYING.txt`.

The win-percentage model, the severity thresholds and the mate rule are reimplemented from the
formulas Lichess publishes (https://github.com/lichess-org/lila, AGPL-3.0); no lila source code is
included.

Vite's build itself and the other development tools (TypeScript, Vitest, Playwright,
fake-indexeddb) are not part of the distributed app; of Vite, only the small module preload helper and
polyfill listed above end up in the bundle.

Game data is fetched at runtime from the public [Lichess API](https://lichess.org/api) and the
[Chess.com Published-Data API](https://www.chess.com/news/view/published-data-api). Neither
service is affiliated with this project.
